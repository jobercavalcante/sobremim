# .qoder — Skills autorais

Este repositório reúne **skills geradas por mim** (Jober Cavalcante), documentando o meu "DNA de desenvolvimento" e boas práticas consolidadas a partir de projetos reais.

## O que é

Cada pasta em [`skills/`](/skills) contém uma skill autossuficiente (com `SKILL.md` e recursos de apoio) que pode ser usada para **criar**, **auditar** ou **reestruturar** projetos seguindo o meu estilo de código.

## Skills disponíveis

| Skill | Descrição |
|-------|-----------|
| [`narrative-landing-pages`](skills/narrative-landing-pages/SKILL.md) | Cria, analisa e reestrutura landing pages estáticas **dark e narrativas** em HTML/CSS/JS puros — zero build, zero dependências. Estilo consolidado a partir de três projetos reais: **StreamNest**, **Sonar Promos** e **ARTEconectaMENTE**. |

## Como usar

Ative a skill desejada (ex.: `narrative-landing-pages`) e siga o `SKILL.md` dela. Cada skill é **autossuficiente**: todos os arquivos necessários vivem dentro da própria pasta, sem depender de documentação externa.
